Main settings:
  -h, --help
    Print this help message

  -u, --url
    The target URL

Crawl settings:
  -p, --prefix
    Also checks the string value with the given prefix. Multiple values are
    possible

  -t, --threads
    Number of concurrent threads

  -d, --max-depth
    The maximum crawl depth

Filter settings:
  -fc, --filter-code
    Filter all responses with this code

  -ft, --filter-type
    Filters the specified content types from the output
